# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.x     | Yes (active development) |

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Use [GitHub Security Advisories](https://github.com/mert-sezer/DevActionDashboard/security/advisories/new) and include:

- A description of the issue
- Steps to reproduce
- Impact assessment (if known)
- Any suggested fix (optional)

We aim to acknowledge reports within 7 days and provide a remediation timeline after triage.

## Safe harbor

Good-faith research is welcome. Avoid privacy violations, data destruction, and service disruption while investigating.
