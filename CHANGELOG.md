# Changelog

All notable changes to Dev Action Dashboard are documented in this file.

## [0.1.0] - 2026-08-17

### Added

- Dashboard, System, Processes, Network, Ports, Docker, Environment, Env Vars, Utilities, and Actions
- Command Palette (⌘K)
- Menu bar extra with live CPU, memory, and storage
- Optional notifications when Actions finish
- System / Light / Dark appearance and accent colors
- First-launch welcome screen
- Sensitive address masking on Dashboard and Network
